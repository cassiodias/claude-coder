# /invaders Implementation Plan (revision 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/invaders` command to puppet-coder that opens a focused pane with a playable Space Invaders, controlled with Button hotkeys. Claude's tool calls drop invaders or power-ups into the game.

**Architecture:** The game logic is pure functions in `hooks/arcade.ts`. `hooks/invaders-game.ts` keeps the running game in the hooks module and steps it on `$.clock.every(100)`. `hooks/invaders-pane.tsx` draws the board and a row of hotkey Buttons. `register.tsx` wires up the command, the pane, close, and tool calls.

**Tech Stack:** TypeScript/TSX Claude Code mod API (`claude-code`). Tests run through `claude plugin test .` (`claude-code/testing`). Type-check with `tsc -p .`.

**Spec:** `docs/superpowers/specs/2026-11-07-invaders-design.md` (revision 2)

## Global Constraints

- Tick: 100 ms. Board: `newGame(36, 14)`. Grid: 3 rows × 6 columns of invaders. Lives: 3. Clearing a wave makes the next one march faster.
- `tough` takes 2 hits. `rapid` allows 3 player shots on screen for 100 ticks. Otherwise 1 shot at a time.
- Hotkeys and buttons: `a` `◀` moves 2 cells left, `d` `▶` moves 2 cells right, `f` `fire`, `p` `pause`/`resume`, `r` `restart` (only drawn on game over or with no game). At most 2 cells of movement per tick in each direction.
- Pane: `$.ui.open({ id: 'invaders', title: 'Invaders', focus: true, closeOnEscape: true, rows: 20 })`. Command answer: `Invaders opened. a/d move, f fires, p pauses, Esc closes.`
- Tool → spawn: Edit/Write → `invader`, Bash → `tough`, Read → `rapid`, other tools → nothing. Applied after `next(e)`, and only when the result isn't an error.
- `bodyColumns < 38` → draw `widen the pane to play`.
- Sync to the loaded copy after each task: `rsync -a --exclude .git --exclude docs --exclude .superpowers ./ /Users/cassiodias/.claude/dev-mods/3620132b-b42d-40e5-9197-6454375f8b52/puppet-coder/`

## Review Focus

1. **Mashing `f`.** It should never put more than 1 shot on screen (3 under `rapid`). → Task 2 `fire is ignored while the shot limit is on screen`.
2. **Holding `d` (key repeat).** The ship moves at most 2 cells per tick. → Task 3 `presses within one tick move at most 2 cells`.
3. **A burst of tool calls.** It never makes an invader appear inside the formation or on the ship row. → Task 2 `spawn is ignored when the top row is full`.
4. **Pressing Esc mid-game.** The clock stops, so nothing keeps redrawing a closed pane. → Task 3 `closing the pane stops the clock`.
5. **Tool calls with no game open.** These do nothing, and the puppet band still counts them. → Task 3 `a tool call with no game changes nothing`. The existing `coder.test.tsx` must still pass.

### Task 2: Game logic (`hooks/arcade.ts`)

**Files:** Create `hooks/arcade.ts`. Test `tests/arcade.test.ts`.

**Interfaces (produces):**
```ts
export type Input = { left: number; right: number; fire: boolean }
export type SpawnKind = 'invader' | 'tough' | 'rapid'
export type Phase = 'playing' | 'paused' | 'over'
export type Invader = { x: number; y: number; hp: 1 | 2 }
export type Game = {
  columns: number; rows: number; shipX: number
  shots: { x: number; y: number }[]; bombs: { x: number; y: number }[]
  invaders: Invader[]; lives: number; score: number; wave: number
  tick: number; phase: Phase; rapidUntil: number; seed: number
}
export const SHIP_WIDTH = 2
export const NO_INPUT: Input
export function newGame(columns: number, rows: number, seed?: number): Game
export function step(game: Game, input: Input): Game
export function spawn(game: Game, kind: SpawnKind): Game
export function togglePause(game: Game): Game
export function cells(game: Game): string[]
```

Geometry and rules:
- Row 0 is the top. The ship is on row `rows - 1`, and its gun is at `shipX` (the left cell).
- The formation starts at row 1. Invaders are 2 cells wide with a 1-cell gap.
- Points: 10 per normal kill, 30 per tough kill.
- Glyphs: invader `▞▚`, tough `█▙` (`▞▚` once hit), ship `▟▙`, shot `╻`, bomb `┇`.

- [ ] **Step 1: Write the failing tests** (import `expect`, `test` from `claude-code/testing`):
  - `a new game`: `newGame(36, 14)` has 18 invaders, 3 lives, score 0, wave 1, and is `playing`.
  - `the ship stops at the walls`: 100 steps of `{ left: 2, right: 0, fire: false }` → `shipX === 0`. 100 steps right → `shipX === 36 - SHIP_WIDTH`.
  - `a shot removes an invader and scores 10`: move under a bottom-row invader, fire, and step until the count drops → 17 invaders, score 10.
  - `fire is ignored while the shot limit is on screen`: 5 steps with fire → 1 shot. After `spawn(g, 'rapid')`, 5 steps with fire → between 2 and 3 shots.
  - `rapid expires after 100 ticks`: `spawn(g, 'rapid')`, then 101 steps → `tick > rapidUntil`.
  - `a bomb on the ship costs a life`: set `bombs: [{ x: shipX, y: rows - 2 }]`, step → 2 lives, and the bomb is gone.
  - `clearing the grid starts a faster wave 2`: `invaders: []`, step → wave 2 with 18 invaders. The ticks until the formation's first sideways move are fewer than in wave 1.
  - `invaders reaching the ship row end the game`: one invader at `y: rows - 1`, step → `over`. Another step returns an equal game.
  - `tough takes 2 hits`: `spawn` on a game with a free top-row slot, then hit it twice → score +0, then +30.
  - `spawn fills the top-row edge slot`: kill the leftmost top-row invader, then `spawn(g, 'invader')` → an invader is back at that slot's x on the formation's top row.
  - `spawn is ignored when the top row is full`: `spawn(newGame(36, 14), 'invader')` deep-equals the input.
  - `pause`: `togglePause` switches between `playing` and `paused`. `step` on a paused game returns it equal. `togglePause` on `over` returns it equal.
  - `cells`: returns `rows` strings of length `columns`, and the last one contains `▟▙`.
  - `same seed, same game`: two `newGame(36, 14, 7)` games stepped 300 times with the same inputs are deep-equal.
- [ ] **Step 2:** Run `claude plugin test .`. Expected: the arcade tests FAIL (module missing), and `coder.test.tsx` passes.
- [ ] **Step 3:** Implement the module. All functions are pure.
  - Order inside `step`: move ship → shots up, bombs down → hits (shot vs invader, bomb vs ship) → march → bombs drop → wave or game-over checks → `tick + 1`.

  - Bombs: an LCG on `seed`. Each tick, with probability `0.03 * wave`, the lowest invader of a random occupied column drops a bomb.
